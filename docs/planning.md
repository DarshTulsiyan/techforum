Project Planning

App

**TechForum** is a technical discussion forum where users can create and share technical posts with titles, bodies, categories, and tags. Other users can browse and search posts, comment, reply to comments, and upvote useful posts.

Core Features

The core features planned for the project are:
1. **User Management** - Create a user profile with basic user details.
2. **Post Management** - Create, edit, and delete technical posts with titles, bodies, categories, and tags.
3. **Search and Browse** - Search for posts using keywords or tags.
4. **Comments and Discussion** - Comment on posts and reply to comments.
5. **Upvoting** - Upvote posts that users find useful.

Stretch Features

If time permits, the following stretch features may be implemented:

1. **Related Posts** - Recommend similar posts based on shared tags.
2. **Popular Posts** - Rank posts based on the number of upvotes.

Collaboration

The team will divide the work into individual features and track them using GitHub issues. Changes will be committed to the shared repository as features are completed.

Definition of Done

A feature is considered done when:

The feature is implemented and works in the application.

Required database, model, controller, view, and route changes are completed.

The feature is committed to Git.

The corresponding GitHub issue is completed.
