## What Went Well

* successfully implemented the main features: users, posts, comments, replies, and upvotes.
* Rails MVC structure helped keep the application organized.
* added RSpec tests for important functionality.
* Added validations to prevent invalid posts from being created.

## What Was Difficult

* understanding has_many relationships between users, posts, comments, and upvotes.
* Handling invalid inputs and displaying errors correctly.
* Setting up RSpec and writing tests for associated models.
* debugging Rails controller and model behavior.

## What We Would Improve Next Time

* Define validations and model relationships earlier.
* write tests alongside each feature instead of adding them later.
* divide development into smaller tasks between team members.
* Test edge cases earlier in development.

## Did the Final App Meet the Original Goal?

* Yes, the app provides a simple technical discussion forum.
* users can create posts and interact through comments, replies, and upvotes.
* the main features planned for the project were successfully implemented.
